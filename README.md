# Портфолио Артура Шакова

Продакшн-статика по `DESIGN-SPEC.md`. Направление «Terminal» (тёмный техно-брутализм, `JetBrains Mono`).
Источник визуальной истины — `Main.dc.html`, `MainEN.dc.html`, `MainMobile.dc.html`, `MainMobileEN.dc.html`.

## Стек

Vanilla HTML + SCSS + немного JS. Без фреймворков. Единственное, что «собирается» — SCSS
(через `sass`) и скриншоты (через `sharp`). Страницы генерируются Node-скриптом из одного шаблона.

## Команды

```bash
npm install
npm run build      # -> dist/  (продакшн)
npm run dev        # watch пересборки + live-server на http://localhost:5173
```

## Структура

```
src/
  build.mjs            сборка: scss -> dist/styles.css, рендер страниц, копирование, картинки
  template.mjs         renderPage('en'|'ru') -> строка HTML
  data/
    projects.mjs       12 работ (порядок = featured)
    strings.mjs        тексты интерфейса RU/EN (+ desktop/mobile варианты копирайта)
  styles/*.scss        _tokens (палитра + vc-машинерия), _base, _layout, секции
  scripts/app.js       прогрессивное усиление: фильтры, смена кадра, клик по строке
dist/                  результат сборки (деплой в корень домена)
```

## Языки

Две статические страницы, **английский — по умолчанию**:

- `/` — EN
- `/ru/` — RU

Пилюли `[ru][en]` в статус-баре — обычные ссылки между страницами. Памяти выбора / редиректа нет.

## Адаптив

Пропорциональное масштабирование `vc()` (как в соседнем `food-chizhik-back-to-school`):
`--wm = --w-cur / --w-base`, всё из макета обёрнуто в `calc(N * var(--wm))`.

- база **390** (mobile) до 959px, **1440** (desktop) от 960px;
- между брейкпоинтами — резина (линейное масштабирование всего: шрифт, отступы, картинки);
- `≥1920` — `--w-cur` замораживается на 1920, контент не растягивается, по краям — леттербокс.

Осознанный компромисс поведения `vc()`: 390→767 мобильная раскладка тянется до ~2×,
960→1920 десктоп масштабируется от ~0.67× до ~1.33×.

## Что осознанно оставлено заглушкой

- **`// preview` для 11 работ** (кроме `glass-decor`) — структура блока настоящая
  (`client · year`, теги, ссылка «открыть сайт»), текст описания — `// описание — TODO`.
  Заполняется в `src/data/projects.mjs`, поле `desc`.
- **`[ показать все ] / [ show all ]`** под таблицей — в макете ведёт на «полный список»,
  которого пока нет; оставлено визуальным акцентом без интерактива.
- **Кнопка «кейс» в preview** — убрана (кейс-страниц нет), осталась одна «открыть сайт».
- **`hill8`** — прод-домен мёртв, ссылка ведёт на страницу Awwwards.
- Колофон `built with vanilla JS + GSAP …` — дословно из артборда (GSAP как библиотека
  не подключён: единственная анимация — мигание каретки, на чистом CSS; при
  `prefers-reduced-motion` гаснет).

## Скриншоты

Исходники — `screenshots/processed/<slug>.jpg` (~1000px). Сборка кладёт в `dist/assets/shots/`
полный кадр и миниатюру, каждый в `webp` + `jpg` (`<picture>`). `dist/assets/shots/`
кэшируется между сборками по mtime.
