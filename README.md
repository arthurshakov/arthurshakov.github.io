# Портфолио Артура Шакова

Продакшн-статика по `DESIGN-SPEC.md`. Направление «Terminal» (тёмный техно-брутализм, `JetBrains Mono`).
Источник визуальной истины — `Main.dc.html`, `MainEN.dc.html`, `MainMobile.dc.html`, `MainMobileEN.dc.html`.

## Стек

Vanilla HTML + SCSS + JS (ES-модули, вендорные Lenis и GSAP). Без фреймворков. Единственное, что «собирается» — SCSS
(через `sass`) и скриншоты (через `sharp`). Страницы генерируются Node-скриптом из одного шаблона.

## Команды

```bash
npm install
npm run build          # -> dist/ (продакшн)
npm run dev            # watch пересборки + live-server на http://localhost:5173
npm test               # запуск автотестов (node --test)
npm run typecheck      # проверка типов TypeScript (tsc --noEmit)
npm run prepare:videos # подготовка WebM/MP4 видеопревью
npm run clean          # очистка собранного dist/
```

## Структура

```
src/
  build.mjs            сборка: scss -> dist/styles.css, рендер страниц, копирование, картинки
  template.mjs         renderPage('en'|'ru') -> строка HTML
  data/
    projects.mjs       17 работ (порядок = featured)
    strings.mjs        тексты интерфейса RU/EN (+ desktop/mobile варианты копирайта)
  styles/*.scss        _tokens (палитра + vc-машинерия), _base, _layout, секции
  scripts/app.js       прогрессивное усиление: фильтры, смена кадра, клик по строке
test/                  автотесты (pjax, видео, аудио, прелоадер, верстка, копирайт)
scripts/               утилиты сборки медиа (prepare-videos.mjs)
dist/                  результат сборки (деплой в корень домена)
```

## Языки

Две статические страницы, **английский — по умолчанию**:

- `/` — EN
- `/ru/` — RU

Пилюли `[ru][en]` в статус-баре — обычные ссылки между страницами. Памяти выбора / редиректа нет.

## Адаптив

Пропорциональное масштабирование `vc()` (как в соседнем `food-chizhik-back-to-school`):
`--wm = --w-cur / --w-base`, всё из макета обёрнуто в `calc(N * var(--wm))`.

- база **390** (mobile) до 959px, **1440** (desktop) от 960px;
- между брейкпоинтами — резина (линейное масштабирование всего: шрифт, отступы, картинки);
- `≥1920` — `--w-cur` замораживается на 1920, контент не растягивается, по краям — леттербокс.

Осознанный компромисс поведения `vc()`: 390→767 мобильная раскладка тянется до ~2×,
960→1920 десктоп масштабируется от ~0.67× до ~1.33×.

## Особенности реализации и дизайн-решения

- **Описания проектов**: все 17 работ в `src/data/projects.mjs` имеют полные двуязычные описания (RU/EN), актуальные теги, ссылки и видеопревью со статическим постером. Заглушек `// описание — TODO` в каталоге нет.
- **Кнопка «кейс» в preview**: убрана (отдельных кейс-страниц нет), оставлена прямая ссылка «открыть сайт».
- **Строка архива `[ показать все ] / [ show all ]`**: строка архива из исходного артборда скрыта в шаблоне, чтобы не оставлять некликабельный элемент интерфейса без реального списка.
- **Ссылки и заметки для завершённых проектов**: для сайтов с завершённым промо (`power-x-time`) ссылки ведут на тестовые стенды с поясняющей плашкой (`note`), а для проектов с недоступным боевым доменом (`hill8`) — на профиль Awwwards.
- **Колофон** `built with vanilla JS + Lenis · no framework · © 2026`: отражает фактический стек фронтенда без UI-фреймворков и две точечные библиотеки (Lenis для инерционного скролла, GSAP для стартового терминального прелоадера).

## Скриншоты

Исходники — готовые скриншоты без адресной строки в `screenshots/without-url-bar/`.
Сборка не снимает сайты и не обрезает интерфейс браузера. Соответствие slug проекта
имени исходного файла задано в `SHOT_SRC` в `src/build.mjs`.

При `npm run build` функция `buildImages()` обрабатывает их через Sharp:

- полный кадр сохраняет исходное разрешение;
- миниатюра уменьшается до 1000px по ширине, без увеличения маленьких исходников;
- для каждого варианта создаются AVIF и WebP с качеством 90, остаётся меньший файл;
- дополнительно сохраняется JPEG с качеством 82 для совместимости.

Результат — `dist/assets/shots/<slug>.*` и `<slug>-thumb.*`. Выбранные современные
форматы записываются в `dist/assets/shots/_manifest.json` и используются шаблоном
в `<picture>`. Папка кэшируется между сборками по mtime исходников; `npm run clean`
удаляет и этот кэш. После замены скриншота запустите `npm run build`: dev-watch
следит только за `src/`. При изменении параметров сжатия очистите кэш перед сборкой.
